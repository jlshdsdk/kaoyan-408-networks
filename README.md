# 考研 408 · 计算机网络带学网站

**在线阅读：<https://jlshdsdk.github.io/kaoyan-408-networks/>**

以王道《2027计算机网络考研复习指导》为底本的 408 计算机网络全程带学站点：

- **目录与教材一一对应**：6 章 34 节，结构取自教材 PDF 真实书签（脚本提取，非人工回忆）
- **紧贴 408 大纲**：考纲内容带「考点」标记，考纲外内容以「课外拓展」明确隔离
- **教材原图**：180+ 张插图全部截取自教材原书扫描页，标注图号与出处页码
- **章末习题**：562 道选择题 + 77 道综合题（取自王道做题本），答案经《答案速查》逐题交叉核对，
  答案默认折叠，综合题含完整分步解答
- **双书融合**：融入高军《深入浅出计算机网络》与湖科大教书匠笔记（15 个「深入浅出」补充框 +
  考纲缺口补入 + 课外拓展·网络安全一览），只收录增量、不重复
- **纯静态 MPA**：无构建依赖，每节一页，图片懒加载，KaTeX（CDN）渲染公式

## 站点结构

```
index.html          首页（章节导航 + 408考纲对照 + 全站目录）
ch1/ … ch6/         每章：index.html 导学 · 各节正文 · quiz.html 习题
assets/css/site.css 公共样式
assets/chN/         该章插图
```

## 本地开发

站点为纯静态文件，直接用任意 HTTP 服务器预览：

```
python -m http.server 8000
# 访问 http://127.0.0.1:8000/
```

`scripts/` 内为生产脚本（内容片段构建器、插图裁剪器、链接检查器等），
`src/` 为各页内容片段——修改片段后运行 `python scripts/pagebuild.py` 重新生成页面。
