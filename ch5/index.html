第5章 传输层 · 导学

依据王道教材章首【考纲内容】【复习提示】整理（教材 P224–P266）· 本章属于 408 考纲范围

考纲要求

408 考试大纲对本章的要求分为三块：

  1. 传输层提供的服务
    • 传输层的功能；
    • 传输层的寻址与端口；
    • 无连接服务与面向连接服务。
  2. UDP
    • UDP 数据报；
    • UDP 检验。
  3. TCP
    • TCP 报文段；
    • TCP 连接管理；
    • TCP 可靠传输；
    • TCP 流量控制与拥塞控制。

复习提示

传输层是整个网络体系结构中的关键层次。要求掌握传输层在计算机网络中的功能、工作方式及原理，掌握 UDP 及 TCP（如首部格式、可靠传输、流量控制、拥塞控制、连接管理等）。其中，TCP 报文分析、连接管理、流量控制与拥塞控制机制，出选择题、综合题的概率均较大，因此要将其工作原理透彻掌握，以便能在具体的题目中灵活运用。

考点分布与备考建议

📌 备考建议
  • 端口号是送分题也是失分题：FTP 21、TELNET 23、SMTP 25、DNS 53、TFTP 69、HTTP 80、SNMP 161 等常见熟知端口号要背到条件反射。
  • UDP 检验：伪首部的作用、二进制反码求和的计算过程多次直接考计算（2014、2018、2021、2024、2025 均有涉及），务必亲手算过几遍。
  • TCP 报文段首部逐字段含义（尤其序号、确认号、数据偏移、六个控制位、窗口）是综合题分析的基础，2012、2021 等年份反复考查。
  • 三次握手 / 四次挥手的报文字段（SYN/ACK/FIN、seq、ack 的取值与变化）与状态迁移是高频考点（2011、2012、2016、2019、2020、2023），要能画出完整时序并计算连接建立/释放的最短时间（1RTT、1.5RTT、1RTT+2MSL 等）。
  • 拥塞控制四算法（慢开始、拥塞避免、快重传、快恢复）的窗口演化分析几乎是必考的综合题素材（2009–2025 多次），要熟练掌握 ssthresh 门限行为与 min[rwnd, cwnd] 发送窗口规则。
