考点一句话结论
★ 组帧四法字符计数（计数含自身1B，计数错即失步）、字节填充（SOH/EOT+ESC转义）、零比特填充（01111110定界，5个连续1后填0，HDLC采用）、违规编码（如曼彻斯特"高-高"，IEEE 802 采用）
★ 码距与检错纠错l = d + c + 1 且 d ≥ c；检 d 位错需 l ≥ d+1，纠 c 位错需 l ≥ 2c+1；纠错能力恒不超过检错能力
奇偶检验码距为 2，只能检测奇数位错，不能定位错误
★ CRC数据左移 r 位后模 2 除以 G(x)，余数即 FCS；只检错不纠错，余数为 0 则接受；以太网 FCS 用 32 位 CRC 且不检验前导码
★ 海明码检验位数 k 满足 2^k ≥ n+k+1；检验位 Pi 放在位号 2^(i-1) 处；校验方程结果 S3S2S1 即出错位号，取反即纠错（单比特纠错）
★ 流量控制层次数据链路层：相邻节点间，收不下就不返回确认；传输层：端到端，用确认中的窗口字段动态调节
★ 三种 ARQ 窗口S-W：WT=WR=1；GBN：1<WT≤2^n−1，WR=1；SR：WT=WR=2^(n-1)；通式 WT+WR≤2^n
★ GBN vs SR 确认GBN 累积确认（ACKn 表示 n 号及之前全部收到）、失序帧丢弃、仅最早未确认帧计时；SR 逐帧独立确认（可用 NAK）、缓存失序帧、每帧独立计时器
★ 信道利用率S-W：U = TD/(TD+RTT+TA)；连续 ARQ：U = N·TD/(TD+RTT+TA)，发不满周期才用此式，NTD ≥ 周期时 U=1；实际速率 = 利用率 × 带宽
★ 四种复用FDM 分频不分时（需隔离频带）、TDM 分时不分频（STDM 按需动态分配时隙）、WDM 是光的频分、CDM 频率时间都共享（码片正交，规格化内积：自身=1、反码=−1、他站=0）
三种 CSMA1-坚持：忙则持续监听、空则立即发（冲突多）；非坚持：忙则随机等待再听（时延大）；p-坚持：时隙信道，空则以概率 p 发送——前两者的折中
★ CSMA/CD用于有线总线/半双工（全双工不需要）；口诀"先听后发、边听边发、冲突停发、随机重发"；争用期 2τ；截断二进制指数退避，k=min(重传次数,10)，16 次失败放弃
★ CSMA/CA（802.11）无线无法冲突检测（信号弱+隐蔽站），改为冲突避免；帧间间隔 SIFS<PIFS<DIFS；NAV 虚拟载波监听 + RTS/CTS 预约缓解隐蔽站；DCF 必选、PCF 可选
令牌传递令牌是特殊控制帧，同一时刻仅一站独占信道，无冲突、公平，适合高负载；用于令牌环（802.5）等
★ 以太网服务无连接、尽最大努力交付（不可靠，纠错交给高层）；曼彻斯特编码；逻辑总线、物理星形
★ MAC 帧目的6B+源6B+类型2B+数据46~1500B+FCS 4B；最短帧长 64B（不含 8B 前导码），数据 46 = 64−18；类型 0x0800 表示 IP
★ MAC 地址48 位（6B）固化在网卡 ROM，高 24 位厂商代码、低 24 位序列号；路由器每个接口一个 MAC
★ 802.11 帧地址地址 1=直接接收方、地址 2=直接发送方、地址 3 视"去往/来自 AP"放实际目的或源地址；MAC 首部 30B，帧体 ≤2312B
★ VLAN802.1Q 在源地址与类型字段间插 4B 标签（0x8100 开头），12 位 VID 最多 4096 个 VLAN，最大帧长 1518→1522B，数据最小 46→42B；隔离广播域，跨 VLAN 通信需路由器/三层交换机；干线链路传 802.1Q 帧
PPPLCP+NCP+封装方法三部分；面向字节；F=0x7E、A=0xFF、C=0x03、协议 2B、信息 0~1500B、FCS 2B；异步链路字节填充、同步链路零比特填充；仅检错不编号确认（不可靠），无最短帧长限制
★ 设备与域集线器（物理层）：冲突域、广播域都不隔离；网桥/交换机（链路层）：隔离冲突域、不隔离广播域；路由器：都隔离；交换机=N端口网桥，N 端口总容量 N×端口带宽
★ 交换机自学习口诀"源进登记，目的查表；同口丢弃，查不到泛洪"；广播/组播帧一律泛洪；表项有老化时间；冗余链路用 STP 消除环路
交换模式直通：收完目的地址即转发，时延小但不检错；存储转发：收全帧检验后转发，可靠、支持速率转换
广域网不等于互联网；节点交换机（非路由器）工作在单个网络内部，存储转发；WAN 三层、LAN 两层

易错清单

⚠️ 考前必看 · 高频翻车点
  1. GBN 最大发送窗口是 2^n−1，SR 是 2^(n-1)——两者不同，别混。
  2. 信道利用率公式：发送周期 = TD+RTT+TA，TA 不忽略时要计入，别把周期当 RTT。
  3. 最小帧长 = 2τ×数据率；凡长度小于 64B 的帧都是冲突异常中止的无效帧。
  4. 最短帧长 64B 不含 8B 前导码；802.1Q 插标签后数据最小变 42B。
  5. CRC 只检错不纠错；奇偶检验只查奇数位错；海明码才能定位并纠单比特错。
  6. 802.11 用 CSMA/CA 不是 CD——无线无法边发边检测冲突，且发送后必须发完整帧。
  7. 集线器两个域都不隔离；交换机只隔离冲突域；只有路由器/VLAN 隔离广播域。
  8. 交换机连主机是全双工无须 CSMA/CD；交换机连集线器仍需 CSMA/CD 且只能半双工。
  9. PPP 无最短帧长限制（点对点不用 CSMA/CD），信息字段最小可为 0B。
  10. 数据链路层窗口尺寸固定，传输层（TCP）窗口可动态变化——"滑动窗口"表述别越层。

一分钟自测五问

问 1窗口约束

用 3 比特对帧编号，GBN 的发送窗口最大是多少？SR 呢？若 GBN 取 3 比特编号、发送窗口为 5，接收窗口最大为多少？

答案

答案：GBN 最大 7（2^3−1）；SR 最大 4（2^(3-1)）；WT=5 时 WR ≤ 2^3−5 = 3。

提示：GBN 上限 2^n−1、SR 上限 2^(n-1)，通式 WT+WR ≤ 2^n。超限的后果是序号回绕后接收方无法区分新帧与重传的旧帧。

问 2信道利用率

1Mb/s 链路 RTT=20ms，分组 1200bit，忽略 TA 与处理时延，停止-等待协议的信道利用率约多少？换 10Mb/s 后呢？

答案

答案：TD=1.2ms，U = 1.2/21.2 ≈ 5.66%；10Mb/s 时 TD=0.12ms，U ≈ 0.596%。

提示：RTT 远大于 TD 时停止-等待利用率极低；连续 ARQ 用 N·TD 扩大分子，NTD ≥ 周期时 U=1。

问 3CSMA/CD

10Mb/s 以太网端到端单程传播时延 25.6μs，最短帧长应是多少字节？为什么凡小于 64B 的帧都要丢弃？

答案

答案：最短帧长 = 2×25.6μs×10Mb/s = 512bit = 64B。

提示：争用期 2τ=51.2μs 内若检测到冲突会立即停发，实际发出的数据必小于 64B——因此小于 64B 的帧只可能是冲突异常中止的无效帧。

问 4设备与域

集线器、以太网交换机、路由器分别隔离冲突域和广播域中的哪一个？交换机如何处理收到的广播帧和未知单播帧？

答案

答案：集线器都不隔离；交换机只隔离冲突域；路由器两个域都隔离（VLAN 也可隔离广播域）。广播帧和查不到表项的未知单播帧，交换机都向除入端口外的所有端口泛洪。

提示：口诀"源进登记，目的查表；同口丢弃，查不到泛洪"。

问 5CRC 与海明码

数据 101001 用生成多项式 1101 做 CRC，发送帧是什么？要纠正 1 位错、检测 2 位错，码距至少各为多少？

答案

答案：101001 左移 3 位后模 2 除 1101，余数 001，发送帧 101001001；检 2 位错需码距 ≥3，纠 1 位错需码距 ≥ 2×1+1 = 3。

提示：CRC 余数非 0 即丢帧，只检错不纠错；海明码用 2^k ≥ n+k+1 求检验位，可定位并纠正单比特错。
