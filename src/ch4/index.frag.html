第4章 网络层 · 导学

依据王道教材章首【考纲内容】【复习提示】整理（教材 P127–P132）· 本章属于 408 考纲范围

考纲要求

408 考试大纲对本章的要求分为八块：

  1. 网络层的功能
    • 异构网络互连；路由与转发；SDN 的基本概念；拥塞控制。
  2. 路由算法
    • 静态路由与动态路由；距离-向量算法；链路状态算法；层次路由。
  3. IPv4
    • IPv4 分组；IPv4 地址与 NAT；划分子网与子网掩码、CIDR、路由聚合、ARP、DHCP 与 ICMP。
  4. IPv6
    • IPv6 的主要特点；IPv6 地址。
  5. 路由协议
    • 自治系统；域内路由与域间路由；RIP 路由协议；OSPF 路由协议；BGP 路由协议。
  6. IP 多播
    • 多播的概念；IP 多播地址。
  7. 移动 IP
    • 移动 IP 的概念；移动 IP 通信过程。
  8. 网络层设备
    • 路由器的组成和功能；路由表与分组转发。

复习提示

本章是历年考查的重中之重，综合题经常和第 3 章、第 5 章、第 6 章串起来出。核心是 IPv4 和路由，历年真题几乎年年涉及，原理要吃透，子网划分、路由聚合这类计算要亲手练熟。其余部分如 IPv6、IP 多播、移动 IP 考得浅，了解即可。

考点分布与备考建议

📌 备考建议
  • 本章是全书分量最重的一章，选择题与综合题并重：IPv4 地址、子网划分、CIDR、路由聚合几乎每年必考计算题，要练到又快又准。
  • 4.1 节的网络层功能以概念辨析为主：虚电路与数据报的对比是经典选择题考点（多次统考），SDN 的南向接口（2022 统考）、拥塞控制与流量控制的区分也要能准确表述。
  • 路由算法与路由协议（RIP、OSPF、BGP）适合对比记忆，注意"算法是方法、协议是落地"的对应关系。
  • 综合大题常将本章与数据链路层（第 3 章）、传输层（第 5 章）串起来考，复习时注意跨章联动。
