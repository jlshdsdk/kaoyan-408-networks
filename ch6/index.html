第6章 应用层 · 导学

依据王道教材章首【考纲内容】【复习提示】整理（教材 P267）· 本章属于 408 考纲范围

考纲要求

408 考试大纲对本章的要求分为五块：

  1. 网络应用模型
    • 客户/服务器模型；P2P 模型。
  2. 域名系统（DNS）
    • 层次域名空间；域名服务器；域名解析过程。
  3. 文件传输协议（FTP）
    • FTP 的工作原理；控制连接与数据连接。
  4. 电子邮件（E-mail）
    • 电子邮件系统的组成结构；电子邮件格式与 MIME；SMTP 与 POP3。
  5. 万维网（WWW）
    • WWW 的概念与组成结构；HTTP。

复习提示

本章内容既可按选择题的形式考查，又可结合其他章节的内容出综合题。因此，牢固掌握本章的几个典型应用层协议是关键。我们生活中的很多网络应用都建立在这些协议的基础上，学习时注意联系实际，提高学习兴趣，才会获得更好的学习效果。

考点分布与备考建议

📌 备考建议
  • 本章是"协议记忆 + 流程理解"并重的章节：各协议使用的传输层协议与端口号（DNS/53 UDP、FTP 21/20、SMTP/25、POP3/110、HTTP/80）是选择题的送分点，务必记牢成表。
  • DNS 的递归查询与迭代查询区分（2010、2016、2020、2021 统考）、FTP 的控制连接与数据连接（2009、2017、2023）、HTTP 的持久连接与非持久连接时延分析（2011、2020、2022、2024）都是反复考查的高频考点，要练到熟练。
  • HTTP 的"无连接、无状态"表述、Cookie 工作原理（2015）、常用请求方法的功能辨析，几乎每隔几年就考一次。
  • 综合题方面，HTTP 页面加载时延可与第 3 章 TCP 拥塞控制、第 4 章 IP/DNS 联动出题，建议结合 6.6 节疑难难点中的"以太网主机开机访问 Web 站点全过程"建立跨层视角。
