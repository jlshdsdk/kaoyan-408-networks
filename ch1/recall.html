第1章 速记手册

考前 30 分钟过一遍 · 全章压缩重组，细节以各节正文与教材为准

知识框架

概述→ 三种交换→ 分类→ 性能指标→ 分层结构→ 协议/接口/服务→ OSI vs TCP/IP→ 小结

核心考点速记

考点一句话要义考法 / 统考年份
网络的概念分散自治的计算机系统 + 通信设备与线路 + 软件，实现资源共享和信息传递；网络由节点和链路组成概念辨析选择题（自治、互连、集合体三要素）
internet vs Internetinternet（互连网）是通用名词、任意协议；Internet（互联网）是专用名词、必须用 TCP/IP经典名词辨析选择
组成与功能组成：硬件/软件/协议（协议是核心）、边缘/核心、通信子网/资源子网；功能：数据通信（最基本）、资源共享、分布式处理、提高可靠性、负载均衡选择题（"自治≠功能"陷阱）
电路交换建立—传输—释放三阶段，独占端到端物理通路；时延小、有序、无冲突、实时性强，但建立慢、线路利用率低、无差错控制时延分析（2025 统考）
报文交换整个报文存储转发，逐跳独立选路；无建连时延、利用率高，但存储转发时延高、缓存开销大时延计算（2013、2025 统考）
分组交换等长分组 + 首部，存储转发 + 流水线；时延更小、更灵活，适合突发式通信；代价是额外开销约 5%～10%、可能失序时延计算高频（2010、2013、2023、2025 统考）+ 综合题
数据报 vs 虚电路数据报：每个分组独立选路、可能失序；虚电路：先建连接、有序但不灵活（详见第 4 章）选择题（数据报"路径不同、不保证有序"）
网络的分类按范围：WAN/MAN/LAN/PAN；按技术：广播式（共享信道）/点对点（存储转发）；按拓扑：总线/星形/环形（多用于 LAN）、网状（多用于 WAN）；按使用者：公用网/专用网选择题（划分依据：广域/城域/局域按作用范围）
速率与带宽速率单位 b/s；带宽 = 数字信道的最高数据率；实际可用速率 = 链路上各环节的最小值（瓶颈）瓶颈速率计算（2024 统考吞吐量同源）
时延总时延 = 发送 + 传播 + 处理 + 排队；发送时延 = 分组长度/发送速率，传播时延 = 信道长度/传播速率，二者不可混选择+大题双料（2010、2013、2023、2025 统考）
时延带宽积 / RTT / 利用率 / 丢包率时延带宽积 = 传播时延 × 带宽（链路上"在飞"的比特数）；RTT 不含发送时延；信道利用率并非越高越好；丢包率反映拥塞时延带宽积入综合题（2023 统考）
体系结构 / 分层体系结构 = 各层及其协议的集合，是抽象的；实现是具体的（实现细节不在体系结构范围内）；上层经接口使用下层服务，不能跨层调用概念题（2010 统考）
协议 / 接口 / 服务协议是水平的（对等实体间），三要素：语法（格式）、语义（动作）、同步（时序）；服务是垂直的（下层经 SAP 向上层提供）；n-SDU + n-PCI = n-PDU = (n−1)-SDU三要素辨析（2020 统考）、SAP 对应（端口号/IP 协议字段/帧类型字段/用户接口）
OSI 七层物（比特）、链（帧，相邻节点，差错+流量控制）、网（分组，路由+拥塞，主机到主机）、传（端到端，进程间，复用/分用）、会（会话管理+检查点同步）、表（格式转换、加密压缩）、应（用户与网络接口）层次功能归属高频（2009、2013、2014、2016、2019、2022 统考）
TCP/IP 四层与五层模型TCP/IP：网络接口、网际（IP 无连接不可靠）、传输（TCP 可靠 / UDP 尽力）、应用；事实标准；学习用五层结构；IP over Everything，Everything over IP层次对应与网际层功能（2011、2021 统考）、封装过程（2021 统考）
OSI vs TCP/IP 关键差异OSI 网络层支持无连接+面向连接、传输层仅面向连接；TCP/IP 网际层仅无连接、传输层两者皆可选择题高频陷阱

易错清单

⚠️ 高危易错
  • 发送时延看"分组长度÷发送速率"，传播时延看"链路长度÷传播速率"，别拿链路长度去除带宽。
  • 速率口径 k=10³、M=10⁶；数据量（存储）口径 K=2¹⁰、M=2²⁰，题目注 1M=10⁶ 时从题。
  • 分组交换总时延用流水线公式：段数×r + (分组数−1)×r，别把每个分组时延简单相加。
  • 电路交换总时间要加"建立连接时间"，数据量小时它可能占大头。
  • OSI 传输层仅面向连接；TCP/IP 网际层仅无连接——两模型服务类型别张冠李戴。
  • 集线器→物理层、交换机→数据链路层、路由器→网络层（2016 统考）。
  • 物理层不封装（无首部）；流量控制"相邻节点间"归数据链路层，"端到端"归传输层。
  • RTT 不包括数据分组本身的发送时延；信道利用率过高会加大排队时延，并非越高越好。

必背数字 · 公式

项目内容
总时延发送时延 + 传播时延 + 处理时延 + 排队时延
发送时延分组长度 ÷ 发送速率
传播时延信道长度 ÷ 电磁波传播速率（常取 2×10⁸ m/s）
存储转发流水线（m 个分组、k 段链路）总时间 = k×r + (m−1)×r，r = 单分组单段发送时延
电路交换总时间连接建立时间 + 数据量 ÷ 带宽
时延带宽积传播时延 × 信道带宽（"在飞"的最大比特数）
信道利用率有数据通过时间 ÷ 总时间
数据单元关系n-SDU + n-PCI = n-PDU = (n−1)-SDU
K/M 口径速率：k=10³、M=10⁶；数据量：K=2¹⁰、M=2²⁰
层次与传输单位OSI 7 层；TCP/IP 4 层；物理层—比特、链路层—帧、网络层—分组/IP 数据报、传输层—报文段/用户数据报
设备最高层集线器 1 层、交换机 2 层、路由器 3 层

一分钟自测五问

带宽 100Mb/s、链路 1000km、传播速率 2×10⁸ m/s，时延带宽积是多少？

答案

传播时延 = 10⁶m ÷ 2×10⁸m/s = 5ms，时延带宽积 = 5ms × 100Mb/s = 500000b（即"在飞"50 万比特）。

OSI 中自下而上第一个提供端到端服务的层是哪层？基于什么地址？

答案

传输层（2009 统考）；基于端口号实现进程间通信。链路层是节点到节点（MAC），网络层是主机到主机（IP）。

协议三要素分别对应：TCP 首部格式、三次握手的动作、报文往返顺序？

答案

依次是语法（数据格式）、语义（做什么动作/如何应答）、同步（时序，事件先后顺序）。

OSI 与 TCP/IP 在"哪层支持哪种服务"上的差别是什么？

答案

OSI：网络层无连接+面向连接皆可，传输层仅面向连接；TCP/IP：网际层仅无连接，传输层无连接（UDP）+面向连接（TCP）皆可。

m 个等长分组经 k 段同速率链路存储转发（忽略传播/处理时延），总发送时延公式？

答案

(k + m − 1) × r，r 为单个分组在一段链路上的发送时延；报文交换则为 k ×（整个报文的发送时延）。
